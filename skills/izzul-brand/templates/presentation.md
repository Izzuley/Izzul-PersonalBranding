# Slides — generation instructions and layout rules

`presentation.html` is a **four-slide functioning HTML sample** (16:9 browser slides, printable as a PDF), not a PowerPoint master. Make additional slides using the same components as appropriate to the actual brief.

## Recommended narrative for a 5–10 slide consulting/research deck

1. **Cover** — dark navy, gold rule and strong proposition; optional *approved* photo.
2. **Decision/problem** — who faces what constraint, with verifiable supporting evidence.
3. **Success definition** — explicit deliverables/metrics and boundaries.
4. **Data / study design** — sample, ownership, limitations.
5. **Method/pipeline** — one diagram with clear labels.
6. **Evidence** — readable plot(s), denominator, metric, CI and data split.
7. **Interpretation** — where features matter; clearly distinguish SHAP from causal effects.
8. **Risks/controls** — leakage, calibration, uncertainty, maintenance and privacy.
9. **Delivery plan** — stages, ownership, dependencies.
10. **Close** — specific next decision and contact.

## Visual rules

- Covers/dividers navy + white + gold; content slides white/light + navy hierarchy.
- Gold as accent, *not tiny text on white*. Violet ribbon is decorative, not an information channel.
- Montserrat if installed; bold all-caps only where legible. Avoid source PDF's tiny typography.
- 16:9 and normally 20px+ body where practical; charts large enough to read from back of room.
- No unlicensed images, official logo inventions or made-up outcome numbers.
- Verify export shows one 16:9 page per slide with no cropped footer; browser print may require 'background graphics'.
